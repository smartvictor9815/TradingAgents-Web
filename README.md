# TradingAgents (extended fork)

This repository is **derivative work** built on top of **[TradingAgents](https://github.com/TauricResearch/TradingAgents)** by [Tauric Research](https://github.com/TauricResearch)—a multi-agent LLM framework for financial analysis ([paper](https://arxiv.org/abs/2412.20138)). You get the **same research engine and terminal program** as the original project; this fork **adds a website you can use in the browser**, **saves your runs so you can open them later**, and **lets you download polished reports**—plus small reliability and safety improvements on the server side.

> **Research use only.** Not financial advice. See the [upstream disclaimer](https://tauric.ai/disclaimer/) and original license.

## Major changes in this fork

Compared with **[TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)**, here is what **you as a user** gain—described without assuming you read the source code.

### How you work with the tool

| | Original project | This fork |
|---|------------------|-----------|
| Main way to run an analysis | **Terminal menus** (the interactive CLI) | **Same terminal experience**, **and** an optional **website** with clear pages for analysis, settings, and LLM providers |
| Where you click and type | Keyboard-driven prompts in a console | **Forms and buttons in the browser** for ticker, date, which analysts to run, language, and API-related settings |

### While an analysis is running

- You see a **live activity log** in the browser instead of only watching text scroll in a terminal window.
- You can **stop a run** from the UI; the system is built so “Stop” actually asks the analysis to wind down rather than only changing a label on screen.
- When a recommendation is ready, the **written explanation** is shown with **normal document formatting** (headings, lists, emphasis) so long text is easier to read than a single block of raw text.

### After it finishes

- There is a **Reports** area where you can **browse past runs**, open one again, or remove it if you do not need it anymore.
- You can **download** a structured report as a **regular file**—for example **Word**, **PDF**, or **Markdown**—suitable for sharing or archiving. An optional **polished summary layer** (still generated by an LLM) can be included when you export, similar in spirit to a fuller write-up.

### What did not go away

- The **original command-line program** still works the same way for people who prefer the terminal or scripts.
- The **underlying idea**—several specialist agents debating and producing a view on a stock—comes from the upstream project; this fork mainly changes **how you drive it** and **what you can do with the output**.

### Privacy and keys (short, practical)

- If you use the website, your **LLM and data-provider keys** are sent to **your own server** (the machine where you started the app), not to us. Anyone who can use that server can in principle see those keys—so treat it like any internal tool: run it on a machine or network you trust, and avoid exposing it to the public internet without extra protection.
- Saved reports and screens that show “configuration” use **masked** values for secrets so a casual glance at history does not display full keys.

## Installation

### Prerequisites

- **Python** 3.10+ (3.12 recommended for smoother wheels; 3.14 may show third-party warnings).
- **Node.js** 20+ and npm (for the web UI).

### 1. Clone and Python environment

```bash
git clone <your-fork-or-mirror-url> TradingAgents
cd TradingAgents

python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate

pip install -e .
# Optional dev tools (pytest):
# pip install -e ".[dev]"
```

### 2. Environment variables

```bash
cp .env.example .env
# Edit .env: set keys for the LLM providers you use (see .env.example / upstream docs).
```

### 3. Run the HTTP API

From the repo root (with the venv activated):

```bash
python -m uvicorn app.api.main:app --host 127.0.0.1 --port 18000
```

Health check: `http://127.0.0.1:18000/api/health`  
OpenAPI docs: `http://127.0.0.1:18000/docs`

### 4. Run the web UI

```bash
cd frontend
npm ci
npm run dev
```

Default dev server: **http://localhost:3000** (Vite proxies `/api` to **127.0.0.1:18000**). If you change the API port, update `frontend/vite.config.ts`.

### 5. Production-style frontend build

```bash
cd frontend
npm ci
npm run build
npm run preview   # serves the built app; ensure API is reachable or configure a reverse proxy
```

### 6. Original CLI (upstream)

The interactive CLI is still available after `pip install -e .`:

```bash
tradingagents
# or
python -m cli.main
```
